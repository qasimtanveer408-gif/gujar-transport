# User manual

**First login:** confirm Business settings/contact order and period-start convention, then create the accounting period. Accounts must be explicitly provisioned; no public signup/default password exists.

**Fleet:** add company, vehicle and driver. Opening odometer is immutable. Assign an active driver from Vehicles; a driver cannot occupy two active vehicle assignments. Start/end duty from Drivers; repeated start does not inflate headcount. Identity details/documents require separate permission. View shows related history and private files.

**Trips:** choose date, vehicle/driver, cycle, route, weight and odometers. Select measured, tank-reconciled or purchase-estimate fuel honestly. Add itemized expenses and fixed agreed commission. Save draft, complete operations, Submit, then authorized Approve/Reject. Rejected edits return to draft. Approved records use a reasoned Void when allowed, not silent edits. A paid source requires reviewed correction.

**Maintenance/oil:** enter invoice items and optional linked trip; oil data includes quantity/specification/history. Inconsistent history enters Review until corrected. Approve posts each item once. Do not duplicate the invoice in trip expenses. Office expenses similarly draft/approve/void. External booking recognizes only commission; own-trip booking does not duplicate freight.

**Driver money:** loans support Opening/Disbursement and existing-loan Repay. Opening does not create expense/cash; excessive repayment is rejected. Earnings accrue salary/allowance/reward with the actual agreement; payments allocate to unpaid earnings without a second expense. Advanced deductions/advances/payroll recovery are pending, not hidden balance edits.

**Reports/accounts:** Today cards use Karachi dates; performance filters affect charts/rankings separately. Reports support scoped CSV/XLSX and browser Print/Save PDF. Master-data registers are current records; transaction dates filter dated reports. Close requires a reason and no submitted trips; review other drafts yourself. Reopen preserves snapshots.

**Administration:** create users and roles within delegation authority. Assign vehicle scopes for assigned grants. Disabled users lose access; last Super Admin is protected. Audit is read-only to staff. CSV imports cover vehicles/drivers, preserve source reference, preview rows and commit atomically. Existing duplicates are rechecked at commit. Alert thresholds are configurable by settings administrators.

**Owner recovery:** privately configure setup environment, run reset:admin interactively, confirm exact target/email, then remove the password and disable bootstrap. Ordinary-user recovery UI remains pending.
