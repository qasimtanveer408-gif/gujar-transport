# Report data mapping

Runtime data comes from `public.reference_dataset` under caller RLS in one stable SQL statement snapshot. Photos are layout references only. Exports are not limited to the register page; over 50,000 records fails explicitly and asks for narrower filters. Reference previews, PDF and XLSX consume the same `ReportDocument` contract. A later download is a fresh authorized snapshot and can reflect intervening edits.

Office and oil are A4 landscape; monthly and combined are A3 landscape for readability; supplementary driver details are A4 landscape with continuation pages. Reports are deliberately labelled INCOMPLETE whenever unresolved sources affect finalization. Unknown cells are blank/dashes, never invented zero.

## Mapping qualifications

- `company` requires confirmation: manufacturer versus the distinct owner-company relationship. No historical values were merged.
- `pp`/`punjab police` map to existing fines_permits (documented fines/permit fees), not an inferred payment purpose. Please confirm this category is the intended scope.
- Office `com` is brokerage commission, `total` its daily sum, `Bill` daily unallocated approved office expense, and `P/L` their difference. Daily cells merge across bookings. Allocated vehicle costs remain on vehicle accounts; quoted carrier freight is excluded from brokerage revenue. External driver name has no separate source. Confirm driver_contact is always a mobile number.
- One oil row per vehicle uses latest approved change through cutoff; multiple same-day readings follow existing database date/ID order, so sub-day chronology cannot be guaranteed without source times. Invalid previous/closing sequences are withheld.
- Monthly first DESEL is PKR; second DESEL is measured matched litres. Report calculations use approved source records; draft/submitted operations are excluded from the revised reference calculation. The legacy monthly-accounts report remains available separately. GBT is a decorative brand separator, not an extra financial column.
- The combined Other Exp. cell aggregates service, parking and other so the ten-category total reconciles. Cycle is verified route text, not cycle no. Weight/cycle no remain in the full-field register; handwritten placements need confirmation before adding reference columns.
- Supplementary driver Sale/expense/profit explicitly mean recorded approved trip fare/cost/result. Its graph plots the recorded trip result; Excel uses numeric data bars. This is a supplementary layout, not an exact match to an absent printed template.
- Canonical reconciliation lists gross fare, brokerage, trip costs/result, other current costs, overhead and operating result separately. Carried balances and the final printed figure stay unavailable until their meanings are confirmed.
- Excel files contain typed dates/numbers and text identifiers; PDF embeds the included Open Sans font. CSV is flat data only. Monetary values exceeding lossless Excel numeric precision are rejected rather than silently rounded; use CSV.
